## Highlights
- Centralized reservations, front desk, and housekeeping in one system
- Accessible from any modern web browser, with no local software to maintain
- Built by Oracle Hospitality for single-property and multi-property hotel groups

## Overview
So what is Opera PMS? It's Oracle Hospitality's property management system — most commonly deployed today as OPERA Cloud — used by hotels to handle reservations, check-in/check-out, room assignments, billing, and guest profiles from a single system. Because it runs as a cloud service accessed through a browser, hotel staff can use Opera PMS on Windows or Mac devices without installing dedicated client software, and Oracle handles hosting, updates, and infrastructure behind the scenes.

## Features
- `[Reservations]` Manage bookings, availability, and rate plans in real time
- `[Front Desk]` Handle check-in, check-out, and room assignments
- `[Housekeeping]` Track room status and coordinate cleaning schedules
- `[Guest Profiles]` Keep guest history and preferences across stays
- `[Integrations]` Connect with point-of-sale, payment, and other hotel systems

## System Requirements
- OS: Any Windows or Mac computer able to run a current, supported web browser
- Processor: Whatever the browser itself requires to run smoothly
- Memory: Standard office-computer memory is generally sufficient
- Storage: No significant local storage is needed, since Opera PMS runs in the browser

## Installation
1. Opera PMS isn't a self-service download — contact Oracle Hospitality or an authorized partner to set up OPERA Cloud for your property.
2. Oracle's implementation team provisions and configures your property's environment.
3. Staff sign in through a supported web browser using the credentials issued for your property.

## Getting Started
New staff typically start with a short OPERA Cloud training session covering navigation, reservations, and front desk workflows. From there, day-to-day use centers on the dashboard for arrivals and departures, a reservation screen for bookings, and role-based access so each team member sees the tools relevant to their job.

## FAQ
**What is Opera PMS?**
Opera PMS is Oracle Hospitality's property management system for hotels, most commonly used today in its OPERA Cloud form.

**Is Opera PMS the same as OPERA Cloud?**
OPERA Cloud is Oracle's current cloud-based version of the Opera PMS product line; some properties still run the legacy on-premise OPERA system.

**Does Opera PMS work on Mac computers?**
Yes — since it runs through a web browser, Opera PMS can be accessed from Mac or Windows computers alike.
